# RetailPro - Base de datos y consultas SQL

## Descripción del proyecto

RetailPro es un proyecto de análisis de datos orientado a la gestión comercial. El objetivo es organizar información de ventas, clientes y productos para obtener datos útiles que permitan analizar el rendimiento del negocio y facilitar la toma de decisiones.

Este repositorio contiene la creación de la base de datos y diferentes consultas SQL desarrolladas durante el proyecto.

## Herramientas utilizadas

- **SQL Server:** sistema de gestión de bases de datos.
- **SQL Server Management Studio (SSMS):** entorno utilizado para crear la base de datos y ejecutar consultas.
- **GitHub:** plataforma utilizada para almacenar y documentar los archivos del proyecto.
- **ChatGPT:** herramienta de inteligencia artificial utilizada como apoyo para revisar, optimizar y documentar consultas SQL.

## Estructura del repositorio

Los principales archivos del proyecto son:

- `ventas_tech_db.sql`: creación y carga inicial de la base de datos.
- `m4_consultas_negocio.sql`: consultas SQL para responder preguntas del negocio.
- `m5_consultas_joins.sql`: consultas que relacionan las tablas de ventas, clientes y productos.

## Cómo ejecutar los scripts

1. Abrir SQL Server Management Studio (SSMS).
2. Conectarse al servidor de SQL Server.
3. Abrir el archivo `ventas_tech_db.sql` y ejecutar el script para crear y cargar la base de datos.
4. Abrir `m4_consultas_negocio.sql` y ejecutar las consultas de análisis comercial.
5. Abrir `m5_consultas_joins.sql` y ejecutar las consultas que relacionan las diferentes tablas.
6. Revisar los resultados obtenidos en SQL Server Management Studio.

**Importante:** Se recomienda ejecutar primero el script de creación de la base de datos antes de ejecutar las consultas de los módulos siguientes.

## Objetivo del proyecto

Aplicar conocimientos de bases de datos y SQL para transformar información comercial en resultados útiles para el análisis de ventas, productos y clientes.
